# Project Details and Goal

## Project Goal
To build the **Front Gate** of the Grocery platform — a standalone, highly attractive, and interactive customer-facing web application. It must provide a "Flipkart-level" user experience for both retail (B2C) and wholesale (B2B) customers.

## Key Constraints
- Must use Next.js, Vercel, Supabase, and GitHub.
- Do NOT build the backend inventory or logistics management systems in this repo.
- Maintain the "Creamy Green" brand identity.
- Build the integration layer (API connectors) so the frontend is ready to plug into the separate backend systems in the future.

## Current State
Transitioning from a monolithic Vanilla JS prototype to a production-ready React (Next.js) frontend architecture.
